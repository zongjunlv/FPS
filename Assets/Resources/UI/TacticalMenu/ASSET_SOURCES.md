# Menu artwork sources

- `lobby-backdrop.png`: [Tactical FPS Lobby Background](https://www.summerengine.com/asset-store/tactical-fps-lobby-background-f70acd76), CC0. Used as concept-art backdrop, not a gameplay screenshot.
- `nescia-*.png`: selected sprites from [Wenrexa Assets: UI Minimalism SciFi](https://opengameart.org/content/assets-ui-minimalism-scifi), CC0. Original archive contains 33 PNG sprites and the source PSD.
- `NotoSansSC.ttf`: [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc), SIL Open Font License 1.1; the complete license is included in `NotoSansSC-OFL.txt`.

Only selected source sprites are included. The `TacticalMenuAssetImporter` imports them as Unity UI sprites.

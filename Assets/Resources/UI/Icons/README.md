# HUD 图标来源

- `weapon-rifle.png`、`weapon-handgun.png`、`ammo.png`：项目已有 Low Poly Shooter Pack Free Sample 资源的 HUD 图标副本，仅用于统一的 Resources 图标目录。
- `health.png`：Iconfont `heart-pulse-line`，图标 ID `41713177`。
- `armor.png`：Iconfont `shield-line`，图标 ID `41713137`。

Iconfont 图标当前作为开发候选素材；正式商用或公开发行前仍需复核原作者授权。运行时图标目录在资源缺失时会自动使用程序化占位 Sprite，不会导致 HUD 空引用。

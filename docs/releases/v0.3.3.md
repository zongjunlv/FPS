# v0.3.3：ESC 退出客户端与退出清理

## 本次发布范围

发布完整 macOS Universal 与 Windows x86_64 客户端，并同步对应源码。两平台均为非开发 Player 构建，包含模式入口、教学、战斗准备、联机大厅和 CityNew 五个正式场景。

本版保留 v0.3.2 的战斗内容与同步修复，新增全屏客户端的明确退出入口。不变更账号／房间 API、战斗协议、服务器部署、账号数据库或认证密钥，不包含公网延迟优化。

## 如何退出

- 登录、模式大厅、角色选择及房间页面：按 ESC 打开“退出客户端”确认窗口。
- 教学、单人或联机战斗：按 ESC 打开既有暂停菜单，选择“退出客户端”。继续游戏、存档和返回大厅仍保持原有入口。
- 确认窗口选择“取消”或再次按 ESC：保留原页面、输入框内容、焦点与暂停状态；关闭窗口的同一帧不会把 ESC 传给底层页面。
- 选择“确认退出”：关闭客户端。联机时先尝试离开房间并清理连接，网络异常时最多等待 5 秒，不因暂停或超时一直困在程序中。
- 退出不会自动保存未保存的单人战局，也不会注销账号或删除本地登录会话。

## 修复细节

- 退出确认窗口统一显示鼠标，阻止移动、射击、切枪和底层 UI 快捷键穿透。
- 教学暂停界面不再重复抢走退出窗口的按钮焦点；单人暂停菜单按窗口大小整体缩放，容纳新增按钮。
- 等待创建／加入房间响应时退出，接收迟到响应后仍尝试离开对应房间，降低残留房间风险。强制结束进程或持续断网时，仍依赖服务端既有房间过期机制兜底。

## 验证与限制

- Unity 编译通过；本轮相关测试 55 项通过：退出窗口 PlayMode 13 项、房间进入／退出 EditMode 14 项、登录／模式大厅／教学暂停／HUD 回归 PlayMode 28 项。
- 测试以注入的终止回调验证退出流程，不在测试中真的关闭编辑器；正式客户端执行 `Application.Quit()`，编辑器执行停止 Play。
- 本轮不增加双人公网通关或网络延迟达标声明。公网联机延迟偏高仍待后续优化。
- macOS 使用 ad-hoc 签名，未经过 Apple 公证。Windows 为 macOS 交叉构建，未在本机进行 Windows 原生运行测试。

## 下载与兼容性

附件见 [GitHub Release v0.3.3](https://github.com/zongjunlv/FPS/releases/tag/v0.3.3)：两个完整客户端 ZIP、`SHA256SUMS.txt` 及两平台构建清单。

产品版本为 `0.3.3`，账号／房间 API 应用兼容版本为 `0.1.0`，战斗协议为 `2`，内容版本为 `citynew-v1`。与 v0.3.2 的网络协议兼容，已注册的自建账号继续使用，无需重新注册。

macOS 解压后运行 `FPS-PVE-Demo.app`；Windows 解压后运行 `FPS-PVE-Demo.exe`，必须保留 ZIP 内的全部配套文件与目录。两个玩家均更新本版即可使用相同退出功能。

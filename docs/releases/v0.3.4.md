# v0.3.4：账号界面跳转与联机场景就绪确认

## 本次发布范围

发布与同一源码提交对应的 macOS Universal、Windows x86_64 完整客户端。保留原有五个正式场景、账号和房间接口、战斗协议及 CityNew 内容版本；不需要重新注册账号，也不修改服务器部署。

## 修复内容

- 登录后在模式大厅与联机大厅之间切换时复用本进程已验证的账号会话，不再重复闪现登录页或等待 `/v1/auth/me`。首次启动仍校验本地缓存；主动注销、令牌到期或服务端确认令牌失效时才重新登录。
- 房间操作返回权限不足或账号服务暂时不可用时，不误删当前登录态；旧异步认证响应也不能覆盖新登录的账号。
- CityNew 场景加载后，客户端对场景就绪确认进行有限重试并显示原因；房间、加载轮次或退出状态改变时停止旧请求，避免迟到结果干扰新战局。
- 后台测试使用隔离的合成输入设置，不依赖前台 Game View 焦点。

## 验证与限制

- Unity 后台测试：场景就绪相关 EditMode 24/24、账号界面 PlayMode 10/10、退出窗口 PlayMode 13/13 通过；账号会话无网络回归测试通过。
- 本版未完成公网双客户端通关验收，也不声称已解决公网延迟问题。
- macOS 客户端为 ad-hoc 签名、未经过 Apple 公证；Windows 客户端为 macOS 交叉构建，尚未在 Windows 上原生运行验证。

## 下载与兼容性

附件见 [GitHub Release v0.3.4](https://github.com/zongjunlv/FPS/releases/tag/v0.3.4)：两个完整客户端 ZIP、`SHA256SUMS.txt` 和构建清单。

产品版本为 `0.3.4`；账号／房间 API 应用兼容版本仍为 `0.1.0`，战斗协议仍为 `2`，内容版本仍为 `citynew-v1`。两个玩家应使用相同的新版客户端测试联机。

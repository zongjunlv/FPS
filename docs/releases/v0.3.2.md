# v0.3.2：CityNew 联机表现与权威同步修复

## 本次发布范围

同步当前修复源码与完整 macOS Universal、Windows x86_64 客户端。两平台均为正式 Player 构建，包含模式入口、教学、战斗准备、联机大厅和 CityNew 五个场景，不使用仅 CityNew 的开发验收包。

本版用于继续双人公网体验测试，不在此次发布中追加延迟优化。远程服务器保持已部署的协议第二版程序，数据库与认证密钥不变。

## 包含的修复

- 敌人模型改为纯网络表现实例，处理补生成、异步复用、模型与血条锚点，以及近地导航误吸屋顶。
- 世界快照按时间线表现，动画依据实际速度和服务端攻击时刻；隔离客户端本地 AI 与伤害逻辑。
- 修正持续输入发送、时钟追踪、预测重放及碰撞对账；服务器 60Hz 模拟与 20Hz 完整快照分离。
- 射击使用实际方向和显示 Tick，服务器按同代次历史命中区域判断；UDP 快速反馈与可靠补漏去重，并同步弹药。
- 联机掉落、背包、拾取列表和中文升级卡片复用单机视图，数据与结算由服务器负责。
- 修正退出、连接失败、重入时的网络生命周期和鼠标恢复。
- 同步账号输入校验、Tab 切换、光标、退出账号入口、房间清理及战术风格界面资源。

## 已有验证与已知问题

- 前一轮 Unity 回归：EditMode 105 通过、1 条件跳过；PlayMode 178 通过。Python 回归 94 通过。
- 本地独立权威进程与两个客户端已完成清怪、经济、终端、撤离和结算。受控网络压力结果来自启用模拟器的开发验收包，不将普通 Release 中未实际生效的模拟标签视为压力验证。
- 2026-09-29 用户反馈：公网最新版已修复多数敌人飞天、可见命中扣血不匹配、掉落和升级表现不一致等问题。
- **公网延迟仍偏高，尚未完成本轮双人公网全流程体验确认。** 这次仅发布现有修复，不宣称延迟问题已解决，也不宣称所有网络环境均已通过。
- macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 产物由 macOS 交叉构建，未在本机进行 Windows 原生运行测试。

## 下载与兼容性

客户端附件位于 [GitHub Release v0.3.2](https://github.com/zongjunlv/FPS/releases/tag/v0.3.2)。两名玩家应使用本版完整 ZIP，解压后保留全部配套目录。

产品版本为 `0.3.2`，账号／房间 API 应用兼容版本仍为 `0.1.0`，战斗协议为 `2`，内容版本为 `citynew-v1`。产品版本升级不要求重建账号库；原自建账号可继续登录。旧 v0.3.0 客户端使用战斗协议第一版，不应继续用于当前服务。

Release 附 `SHA256SUMS.txt` 与两平台构建清单。清单记录源码完整提交号、Unity 和包版本、正式场景列表、非开发构建选项及构建结果，便于核对下载包来源。

完整修复证据和验证边界见 [交付摘要](../networking/coop-parity-repair-results.md)、[修复记录](../networking/coop-parity-repair-progress.md)。

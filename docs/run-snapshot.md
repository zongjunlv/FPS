# 最小战局快照

在 CityNew 中按 **ESC** 打开暂停菜单，可在同一界面继续游戏、保存、读取或开始新战局。选卡、背包和结算界面处于最上层时，ESC 优先处理当前界面。

- **保存战局**：保存到一个本地槽位，覆盖该槽位的旧内容。
- **读取战局**：校验存档后重新加载场景，恢复玩家关键状态；没有存档或内容无效时保留当前战局并提示原因。
- **开始新战局**：生成新种子、重新开始，不读取或删除旧存档。
- **返回游戏**：关闭菜单并解除本菜单的暂停锁。

保存内容为版本1纯数据：种子、生命、护甲、当前武器、所有已装备武器的弹匣/备弹、升级等级和选择历史。存档位置是 `Application.persistentDataPath/run-snapshot.json`，不在项目 Assets 中。

本轮**不保存波次进度、敌人位置、背包、经验进度或任务阶段**。读取后，这些系统从初始状态开始。这是最小玩家快照，不是完整中途续关。

恢复顺序：初始化玩家组件 → 验证版本/ID/等级/数值 → 重建永久升级效果 → 恢复武器弹药与当前武器 → 恢复生命护甲 → 绑定奖励与启动波次。已选择的即时回血、护甲卡不再次发奖；换弹和切枪动画不作为存档状态恢复。

校验值使用固定格式与排序的 SHA-256，用于验证序列化和恢复一致性，不是防作弊签名。文件损坏、未知版本、重复ID、不一致选择历史和非法数值会被拒绝。原子替换、备份和版本迁移留给后续 Issue。

## 验收

1. 开火消耗弹药，受到一定伤害并选择升级后，按 ESC，在暂停菜单中保存。
2. 再开几枪或受伤，按 ESC 读取。检查保存时的武器、弹药、生命护甲和升级恢复，且没有额外选卡或回血奖励。
3. 选择“开始新战局”，确认升级清空、生命初始化；随后仍能读取之前的存档。

# CityNew 联机 PvE 修复交付摘要

## 当前结论

代码修复、本地组件回归与真实 UDP 双客户端完整流程已通过，Linux 服务端已更新。2026-09-29 用户在公网确认最新版修复多数敌人飞天、命中扣血不匹配、掉落与升级表现不一致问题，但反馈延迟仍高。按用户要求，本轮先同步源码和完整双平台客户端至 [v0.3.2](../releases/v0.3.2.md)，暂不追加延迟改动；双人公网完整通关与延迟体验仍待测试。

此前校园网络下未完成的公网自动化记录继续保留，不用后续用户反馈抹除该次失败，也不把本地成功替代公网验证。本次发布不继续公网自动化测试。

## 已实施

- 五类正式敌人使用纯表现资源；隔离客户端 AI、寻路与伤害，防止异步旧模型挂到新实体。模型保持真实尺寸，血条与模型就绪、锚点和投影同步。
- 敌人按带 Tick 的快照时间线移动，动画按实际表现速度及服务端攻击时刻驱动；导航防止近地采样误吸屋顶，保留真实坡道与空中玩家追踪规则。
- 客户端持续采样与发送，不再每份快照只准发送一次；服务器保持 60Hz 模拟、20Hz 完整快照，停更、输入积压和恢复均有界。
- 本地移动预测与服务端共用碰撞求解；计算状态完整对账／重放，视觉平滑独立，修正冲刺和重连首条拒绝输入造成的连续位移拒绝。
- 射击上传实际方向及显示 Tick，服务端采用同模型、同代次的历史命中区域；即时 UDP 反馈与可靠补漏去重，命中／拒绝与弹药正确对账。
- 联机复用单机立体掉落、F 拾取列表、消耗品背包和中文升级卡片；数据来自服务器，提交意图而非客户端自行结算。
- 退出、超时和重入等待旧网络真实关闭，旧回调不能污染新连接；恢复光标、输入锁与大厅操作。

上述四档来自实际启用模拟器的开发验收包，追加门禁后重检仍通过。完整 Release 的本地正常档另测 P95 19.0ms、零预测分歧；其标称延迟档实际仍仅约 15ms RTT，旧报告的矩阵 `Pass` 已复核为无效，不能替代开发包压力证据。详见修复记录最后一节。

本机权威进程为 macOS 无图形 Player fallback，控制面为本地验收身份；正式腾讯云采用真正 Linux Dedicated，二者不混同。

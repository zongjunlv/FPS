## 本轮修改

- 敌人客户端加载纯表现 Prefab，仅保留网格、骨骼、材质、Animator 和校准元数据；禁止延迟 Awake 再安装本地寻路/伤害。异步加载按实体与模型代次检查，旧请求不能绑定新对象。
- 正式模型不随 LOD 缩放；模型未就绪时不显示孤立血条。血条采用各模型锚点，屏幕后方/近裁剪面外不绘制。
- 短暂不完整世界帧保留同战局最后显示的完整模型/位置，最长 0.75 秒；换战局、断连、禁用或超时立即隐藏，完整状态恢复后复用已加载模型。
- 服务端导航起点仅允许 0.5 米近地采样，避免脚下导航缺失时瞬间吸附到头顶不连通的屋顶。真实坡道与五类敌人对空中玩家的平面追踪对照仍通过；不将所有 Y 坐标锁死。
- 移动动画跟随插值后的实际速度；攻击跟随权威攻击 Tick。动画根运动和动画事件关闭，无跑步片段的悬浮模型只使用有限的视觉偏移。
- 客户端采样输入不再把每份服务端快照当作下一次发送许可。预测、队列、恢复追赶均有界；停更恢复和战局切换重建时钟原点，不回放旧开火/跳跃。
- 同一战局的时钟恢复不再倒退已发送输入 Tick；真实战局重启才重新从低 Tick 开始。对账后的完整重放状态用于计算和发包，画面平滑偏移单独有界衰减；避免平滑一半的位置导致连续不可能位移拒绝。
- 服务端保持 60Hz 模拟，完整世界状态按 20Hz 原子发布；接受或拒绝的开火即时反馈原输入序号、原因和权威弹药，不等待下一次世界发布。
- 射击反馈增加快照实际覆盖的弹药确认序号，独立于移动确认。HUD 不重复扣除已反馈的预测开火；提前拒绝只结算本枪，批处理、乱序、重复和可靠补漏有实际组件回归。
- 武器向准星/当前显示命中体汇聚枪口射线，上传独立射击方向与显示 Tick；服务器对同代敌人历史位置使用与表现校准一致的命中盒。近距视差、正式散布与独立有界相机后坐力预算分别覆盖，不扩大命中盒。
- 当插值缓冲耗尽，射击采用目标实际显示姿态的 Tick，而不是已经超出缓冲的时钟游标；每枪清理上次解析结果，未解析目标时不复用旧值。
- 联机掉落恢复共用立体包体；背包、附近物品列表和升级卡片复用单机视图，通过服务器投影与意图适配，不再执行客户端本地结算。不完整快照不能清空待确认请求或释放模态锁。
- 关闭/超时/重入等待旧网络真正停止，阻止旧回调污染新连接；失败和退出恢复时间、鼠标及大厅操作。保留已验收的单机和教学流程。
- 模型日志明确记录就绪、局部/世界坐标及实体快照 Tick；未加载模型指标不伪装成根位置。分析器过滤可选非有限模型指标，没有可测证据时返回不足，而不是宣称正常。

# Domain docs

本项目采用单上下文结构。

## 开发前读取

- 若仓库根目录存在 `CONTEXT.md`，在分析或实现功能前读取。
- 若 `docs/adr/` 中存在与当前功能相关的架构决策记录，在修改对应模块前读取。
- 文件不存在时继续工作，不应为了形式提前创建没有实际内容的领域文档或 ADR。

## 目录约定

- 领域上下文与术语表：`CONTEXT.md`
- 项目级架构决策：`docs/adr/`
- Agent 与 Issue Tracker 配置：`docs/agents/`

Issue 标题、验收标准、测试名称和代码概念应优先使用 `CONTEXT.md` 中已经定义的术语。若实现方案与现有 ADR 冲突，必须明确指出冲突，不能静默覆盖原决策。

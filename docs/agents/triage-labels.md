# Triage labels

工程技能使用以下五种标准分诊角色。右侧名称是本仓库实际使用的 GitHub 标签。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由代理独立实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不计划处理 |

当技能使用标准角色名称时，应应用本表对应的 GitHub 标签，避免创建同义标签。

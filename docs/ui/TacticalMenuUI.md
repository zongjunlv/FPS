# 战术菜单 UI 规范

## 覆盖范围

- 账号登录与注册：独立状态、明确输入焦点、密码可见性、错误反馈。
- 模式选择：教学、单人战斗、联机 PVE 三张横向功能卡片。
- 联机大厅：公开房间浏览、邀请码加入、角色整备、双人席位、准备与开始战局。

## 视觉语言

- 背景：近黑蓝 `#02060A`，使用低对比度扫描线和战术网格提供层次。
- 主强调色：青绿，用于当前选择、可执行主操作和输入焦点。
- 辅助强调色：琥珀代表单人战斗，绿色代表联机与正常网络状态，红色仅用于错误和危险操作。
- 信息层级：英文协议标签 → 中文主标题 → 说明 → 操作；避免多个相同权重的大按钮竞争注意力。
- 卡片：细描边、顶部信号线、角标和轻投影，不使用厚重渐变或大面积高饱和背景。

## 交互规范

- 键盘、手柄和鼠标共享同一套 `Selectable` 导航状态。
- 输入框必须提供常态、聚焦和错误状态；聚焦时显示青色描边、底部高亮线和输入光标。
- 主操作使用高亮实心按钮；次操作使用深色按钮；退出和离开房间使用危险色。
- 按钮禁用时保留文字可读性，并通过状态栏解释不可执行原因。
- 房间行同时显示房间名、地图、人数和网络状态；选择后显示左侧高亮标记。

## 资源与实现

- 图标来自 Kenney Game Icons，许可为 CC0 1.0，项目内保留 `Assets/ThirdParty/Kenney/GameIcons/LICENSE.txt`。
- 页面继续使用项目现有 uGUI 运行时构建方式，不引入额外 UI 框架依赖。
- `TacticalUiTheme` 统一颜色、图标加载、面板装饰和背景扫描线，后续菜单不得重复声明另一套主题色。
- 基准分辨率为 1920×1080，`CanvasScaler` 使用 `Scale With Screen Size` 和 0.5 匹配值。
